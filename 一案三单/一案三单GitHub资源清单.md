## 一、资源包是什么

「一案三单」是面向小学数学课堂的 **"学为中心"** 教学设计资源包：

- **一案**：八段式教学设计（教学主题 → 教学反思，共八段）
- **三单**：预学单（课前唤醒）+ 共学单（课中任务）+ 续学单（课后巩固 + 自评，也称延学单）

资源包共 3 个 Markdown 文件，均可直接复制填写、A4 打印，也可作为模板喂给 Codex 一键生成完整课例。

## 六、使用方法

### 方式一：Codex 一键生成完整课例

把「八段式教学设计模板.md + 三单模板合集.md」内容，或下面这一句话发给 Codex：

> 生成"三上-第一单元-小熊购物"的一案三单教学设计，按资源包模板输出，含预学单、共学单、续学单。

### 方式二：直接填写

下载模板 → 替换占位内容 → A4 打印。
