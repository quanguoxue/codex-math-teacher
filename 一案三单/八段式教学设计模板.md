# 八段式教学设计模板（一案）

> 适用：小学数学各年级课时 ｜ 输出：A4 打印友好 ｜ 设计者：薛国权｜学校：运城市人民路学校
> 配套：`三单模板合集.md`（预学单 / 共学单 / 续学单）

## 使用说明

- 全文共 **8 段**，缺一不可：主题 → 课标 → 目标 → 评价 → 过程 → 作业 → 板书 → 反思
- 每段给出「说明 + 填写区 + 示例句」，直接替换占位内容即可
- 学习目标主语必须是「**学生将能……**」
- 教学过程 3 个任务，每个任务标注：**学生活动 + 教师反馈 + 设计意图**
- 完成后在页面右下角加固定角标：`✨ Codex + DeepSeek 生成 | 薛国权 · 运城市人民路学校`

## 第一段 · 教学主题（教材分析）

【说明】写清年级/册次/单元/课时，分析教材定位、本课核心知识与学生已有经验。

| 项目 | 内容 |
|---|---|
| 年级/册次 | 例：三年级上册 |
| 单元 | 例：第一单元 混合运算 |
| 课时 | 例：第 1 课时 小熊购物 |
| 核心知识 | 例：乘加混合运算的运算顺序 |
| 教材定位 | （本课在单元/学段中的地位） |
| 学生基础 | （学生已有的经验与技能） |

示例句：本课是「混合运算」单元的起始课，核心是乘加混合运算的顺序；学生已掌握表内乘法与加减法，但对"先算乘、再算加"缺少结构性认识。

## 第三段 · 学习目标

【说明】三档必填：**理解 / 技能 / 迁移**；每个目标 = 行为动词 + 行为条件 + 行为标准；主语必须是「学生将能……」。

| 档位 | 目标（学生将能……） |
|---|---|
| 理解 | 用自己的话说出……并解释…… |
| 技能 | 正确计算……（如：三步以内的混合运算） |
| 迁移 | 在生活情境中……（如：用混合运算解决购物问题） |

示例句：学生将能**用自己的话**说出"先算乘、再算加"的道理，并正确计算两步混合运算式题，正确率达到 90% 以上。

## 第四段 · 嵌入式评价

【说明】评价伴随学习全过程，不再是"课后一张卷"：学生自评量表 + 同伴互评 + 教师观察清单。

### 4.1 学生自评量表（4-5 个 ★ 项目）

- [ ] 我能说出算式的运算顺序（★★★）
- [ ] 我能正确计算混合运算式题（★★★）
- [ ] 我能讲清"为什么先算乘"（★★★）
- [ ] 我能用混合运算解决生活问题（★★★）

### 4.2 同伴互评

互读 / 互批 / 互讲：交换作业互批，互讲错因，评出"讲得最清楚"的同伴。

【说明】每个任务三段式：🎒 学生任务 → 🧠 学生可能怎么想 → 👩‍🏫 教师反馈（无痕教学·追问代替评判），并注明设计意图。

- 👩‍🏫 教师反馈：……
- 📐 设计意图：……

### 【任务二】合作探究 · 建构新知

- 🎒 学生活动：……
- 🧠 学生可能怎么想：……
- 👩‍🏫 教师反馈：……
- 📐 设计意图：……

### 【任务三】辨析迁移 · 当堂检测

- 🎒 学生活动：……
- 🧠 学生可能怎么想：……
- 👩‍🏫 教师反馈：……

## 第六段 · 作业设计

【说明】分层设计：基础（打牢）+ 应用（生活）+ 拓展（挑战），标注完成时间与难度。

| 层次 | 内容 | 建议时间 | 难度 |
|---|---|---|---|
| 基础 | （必做，巩固运算顺序） | 10 分钟 | ★ |
| 应用 | （选做，生活情境问题） | 10 分钟 | ★★ |
| 拓展 | （挑战，开放题/自编题） | 10 分钟 | ★★★ |

---

## 第七段 · 板书设计

【说明】板书由学生建构生成：教师只负责把学生的话搬到黑板上（情境 → 探究 → 辨析 → 迁移）。

| 环节 | 板书内容 |
|---|---|
| 情境 | 出示情境图 + 学生命名/列式 |
| 探究 | 学生操作后誊抄的关键结论 |
| 辨析 | 学生讨论出的口诀或规则 |
| 迁移 | 学生自己举的例子 |
