# 安装说明

## 方法一：安装 Skills（推荐）

将 Skills 安装到本地 Codex 环境：

```bash
# 克隆本仓库
git clone https://github.com/quanguoxue/codex-math-teacher.git
cd codex-math-teacher

# 安装全部 6 个 Skill
codex skills install ./skills/one-case-three-sheets
codex skills install ./skills/math-exam
codex skills install ./skills/deep-reading
codex skills install ./skills/oral-arithmetic
codex skills install ./skills/smart-error-book
codex skills install ./skills/fraction-game

# 验证安装
codex skills list
```

## 方法二：使用 Prompts（无需安装）

直接打开 prompts/ 目录下的 txt 文件，复制内容粘贴到任意 AI 对话中使用。

## 方法三：直接使用 Assets

assets/ 目录下的 SVG 图片可直接拖入浏览器查看，或插入课件/文档中使用。

## 环境要求

- Codex CLI（推荐）
- 或其他支持 Markdown/HTML 的 AI 工具
- 浏览器（查看 HTML 输出）

## 自定义

如需修改 Skill 配置，编辑对应 SKILL.md 文件后重启 Codex CLI 即可。
