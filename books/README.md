## 二、六层读书法简介

薛老师用于专业阅读的八段式研读框架，旨在把"读过的书"变成"能用起来的教学力"：

1. **俯瞰全貌**——先建立全书结构地图，知道它在讲什么、属于哪条知识链。
2. **解析核心**——提取作者最核心的 1–3 个主张，不陷入细节。
3. **共情学情**——回到儿童立场：这本书解决了孩子哪类认知困难？
4. **建构支架**——把理论转成可操作的教学支架 / 学习单。
5. **理论溯源**——追溯其学术来源（皮亚杰、布鲁纳、建构主义……）。
6. **萃取要径**——提炼成可迁移的方法论口诀。
7. **大概念双视角**——分别从"学科本质"与"儿童发展"两端审视。
8. **实践转化**——落到一节具体的课、一张具体的单。
