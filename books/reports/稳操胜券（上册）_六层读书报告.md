### 四、核心概念④：拧数、尼姆与 MEX——二进制 / 奇偶的萌芽

第2章引入无偏博弈的"拧数"（nimber）n，0=0，1={0|0}=，并说明"同样大小的两堆之和为零"。第3章给出虚拟尼姆堆原理与 MEX（局外最小数）法则：

若左、右双方在 G 中都有同样的走法可以选择，它们都是尼姆堆 *a, *b, *c, …，则 G 本身可视为一个尼姆堆 *m，这里 m 是不在 a,b,c,… 中的最小整数（0 或 1 或 2 或……）。

——第3章 · 虚拟的尼姆堆以及 MEX 法则

斯普莱格—格隆第理论把"一切无偏博弈都等价于一堆尼姆"这条震撼结论立了起来（第3章 · 无偏博弈的斯普莱格—格隆第理论）。对小学教师，这背后是异或（二进制不进位加）与奇偶配对的雏形——儿童玩"每次取任意根、拿最后者赢"时，已经在和现代计算机理论握手。

### 五、核心概念⑤：可逆行动与优超——化简的两把刀

第3章给出把复杂博弈"瘦身"的两条法则：其一，若某走法能被对手立即逆转且毫不更差，就避开它；其二，若走法 A 总不劣于 B，则 B 被 A 优超，可删去：

如果保留优超选择，删去被优超的选择，则 G 值不受影响。

——第3章 · 删去被优超的选择

这两条法则的本质是"有序思考、去冗余、抓关键"——这正是解题策略教学的核心能力。

## 建构支架

对应第四层：3–5 个可落地学习支架（理论 / 年级 / 步骤 / 观察点）

以下支架均可在普通教室、无需特殊材料完成，每个都标注了对应书中的理论原型。

### 支架一：对称模仿棋（理解"双胞胎论证 / 零值博弈"）

对应理论

第1章"双胞胎论证"——后走者照抄对手走法即稳赢，构造零值博弈（{ | }=0）。

适合年级：二年级（下册"对称"、三年级"趣味数学"拓展）。

操作步骤：① 黑板上画一株左右对称的"小树"（蓝红各半）；② 两人轮流擦掉一条边，先不能动者输；③ 先让一方当"后手模仿者"，体验"你擦左我擦右"为何必胜；④ 交换角色，讨论"不对称时还能模仿吗？"

观察点：学生能否说出"只要图形对称、我永远照着你擦，就轮到你先没得擦"——能说出即建立"对称守恒→必胜"的直觉。

### 支架二：抢数游戏（理解"必胜策略 / 安全数"）

第3章"尼姆 / 拧数 / MEX"与奇偶配对——把胜负归结为"控制模某个数的安全态"。

适合年级：三年级（表内乘除法之后）。

操作步骤：① 从 1 轮流报数，每次 +1 或 +2，先报到 20 者胜；② 让学生自由玩 5 轮，记录谁赢；③ 引导找"不论对方 +1 还是 +2，我都能拉回"的数（3 的倍数）；④ 抽象："安全数 = 20 往前数每 3 个一停"；⑤ 改规则（每次 +1~+3，抢 30）再玩。

观察点：学生能否从"瞎抢"过渡到"主动抢 3、6、9…"——能说出"我要把数控制在 3 的倍数"即达到策略水平。

第 三 篇

## 共情学情

对应第三层：用书中理论反观一线教学痛点

从"策略数学"视角看，儿童在课堂上的典型困难，几乎都能在本书前三章找到"理论原型"。下面用"理论 → 课堂症状"对照，帮教师读懂学生。

### 一、症状①：会做但"换个问法就错"——假理解

书中把"先走者赢"的局势叫模糊博弈，把"后走者赢"的局势叫零值博弈。儿童常只会背"先手必胜"，却分不清"先手必胜"与"后手必胜"的结构条件。这正是书中反复强调的：

把先走先输的局势认作零值，这样的做法可取吗？常言道：要知道布丁的滋味，你最好自己尝一口……（答案是"是"）。

——第1章 · 咱们的办法管用吗？

课堂症状：学生抢数游戏赢了一次，却说不清"为什么 3 的倍数安全"；换堆数就输。根子在"记住了结果，没建立结构"。

### 二、症状②：一遇复杂就乱走——缺"拆解相加"意识

书中所有复杂博弈都靠"拆成分支相加"解决。儿童缺的不是能力，而是"先拆开"的元策略。对应认知框架的认知起点：儿童的前概念是"整体一把抓"。

### 三、症状③：不会"找最简"——被冗余迷惑

简单性法则要求"取最简数"。儿童在分数比较、图形分割中常被"非最简形式"带偏（如认为 6/8 与 ¾ 是"两个不同的数"）。对应 认知冲突：符号形式 ≠ 数值本质。

### 四、症状④：蛮干不回溯——不会"可逆/优超"式自检

第3章的"可逆行动""优超"本质是"走一步想想对手怎么反制、再删去废招"。儿童解题常"一条道走到黑"，缺这一层自我反驳。

### 五、学情诊断要点小结

◎ 教师读懂学生最该注意的 4 点

① 警惕"假会"：能赢 ≠ 懂结构（先手/后手条件不清）。

② 教"拆"先于教"算"：不会分解是多数策略混乱的根源。

③ 把"最简"当铁律：分数、图形、规律都要回到最简形。

④ 培养"对手视角"：每走一步自问"对方怎么反制"，即优超/可逆思维。

### 支架五：删废招擂台（理解"优超 / 可逆"化简）

第3章"删去被优超的选择""避开可逆行动"——保留优者、删去被优超者、回避可被反制的走法。

适合年级：五年级—六年级（解决问题策略单元）。

操作步骤：① 给一个"怎么走都行"的开放题（如凑 24 点、走迷宫）；② 让学生列出所有可能走法；③ 引导挑出"被别的走法全面压过"的废招，划掉（优超）；④ 再引导"这步会被对手立刻反制、毫无更差"的走法，也划掉（可逆）；⑤ 比较"删前 vs 删后"，体会"少即是多"。

观察点：学生能否主动说出"这个选择其实不如那个，可以不要"——能则形成有序枚举与优化的解题习惯。

第 五 篇

## 理论溯源

对应第五层：学术史定位（继承 / 推动 / 被发展 + 三句话贡献 + 修正）

### 一、核心概念①：博弈的"相加"与"值"——结构分解思想

第1章用"蓝—红伐木游戏""滑雪跳跃游戏"引入：一个复杂图形可拆成互不相干的若干部分，总胜负等于各部分"值"的相加。第2章正式定义博弈和：

G + H = { Gᴸ+H, G+Hᴸ | Gᴿ+H, G+Hᴿ }，即从 G+H 出发，局中人只能在某一分支中采取行动。

——第2章 · 任意博弈之和 / 和的结果

并给出一条对教学极为重要的规律：

添加一个零博弈决不会改变结果。

——第2章 · 和的结果

思想史线索：把整体拆成可独立判断的部分再叠加，这正是数学中"分而治之 / 结构分解"的鼻祖式表达。对儿童而言，"先拆开、再合计"是一切运算、图形、统计思维的元认知。

### 二、核心概念②：零位、正、负、模糊——用"谁先走谁赢"给数分类

第2章把两人博弈按结局分为四类（表3）：正值（左方总赢）、负值（右方总赢）、零值（后走者赢）、模糊（先走者赢）。其中"零值博弈"定义尤妙：

若不论谁先走，左方总是能赢则 G 称为正值博弈……若后走者（第二人）总是能赢；G 是一种零值博弈。

——第2章 · 正、负、零值以及模糊局势

第1章的"双胞胎论证"（后走者照抄对手走法，即"东施效颦策略"）正是制造零值博弈的典型构造。这一"对称模仿"后来在小学"取火柴 / 报数"游戏中反复出现。

### 三、核心概念③：{L|R} 记号与"数的博弈观"——关系性地看数

第2章用康威的 surreal 记号把数重新定义：

0 = { | }，1 = {0|}，2 = {1|}，……，½ = {0|1}，−½ = {−1|0}。

——第2章 · 数与游戏的对应

这里 {a|b} 表示"左方可走到值 a，右方可走到值 b"。一个博弈的值是"夹在左、右最优选择之间"的那个最简数——这直接催生了简单性法则：

如果有任何数能满足已知条件，则其中最简单的数就是答案。

——第2章 · 简单性给出答案！

教学启示：分数不是"分子除以分母"的算式，而是"夹在某两个最简数之间、且取最简形式"的位置。这恰好解释了小学课堂里"通分到最简""比较 ¾ 与 ⅝ 谁大"的深层逻辑——找最简、找夹逼。

### 一、在学术史上的位置

《稳操胜券》是组合博弈论的集大成通俗著作，它的理论血脉可上溯到两条线：

继承：1902 年博顿（C. L. Bouton）对尼姆游戏的完整数学分析；1935–1939 年斯普莱格（Sprague）与格隆第（Grundy）独立证明"一切无偏博弈等价于尼姆堆"（书中第2–3章反复引用并命名为"斯普莱格—格隆第理论"）。

推动：康威在 1976 年《On Numbers and Games》中创立 surreal number（超现实数）与 {L|R} 记号，把"数"与"博弈"统一在同一套构造里——本书第2章的"数的博弈观"正是这一突破的通俗化展开。

被发展：此后"冷/热博弈""无穷博弈""热图"（本书第6章起）把理论推向更一般的对策结构，并深刻影响了算法博弈论、程序语言语义（指称语义）等领域。

### 二、向未读此书的同行讲清贡献（三句话）

### 三句话讲清本书学术贡献

① 它把"数"重新定义成一种博弈——{左方可到 | 右方可到}，让加减、分数、大小比较都有了"谁占优"的直观来源。

② 它证明了所有"公平博弈"（无偏博弈）都能化归为一堆尼姆，胜负只需算"异或/配对"——这是计算机算法与奇偶思想的共同祖先。

③ 它用"可逆/优超/最简"三把刀，教人把看似无穷的复杂策略系统一步步化简——这是"化繁为简"这一数学核心素养最生动的方法论。

### 二、作者想让教师带走的三句话

★ 全貌三要点

① 任何博弈都可"拆成几部分相加"，胜负由各部分的"值"共同决定——这是结构分解思想的极致。

② "数"不是静态符号，而是"左方比右方多走几步"的关系——这是动态、关系的数的观念。

③ 复杂博弈靠"可逆 / 优超 / 最简"三把刀化简——这是化繁为简这一数学核心素养的活教材。

### 一、教师行动纲领

### 贴桌行动指南

① 先拆后算——遇到策略问题，先带儿童"拆成互不相干的部分相加"，再谈对错。

② 抓"谁先走谁赢"——用"先手胜 / 后手胜 / 模糊"三分类判断儿童是否真懂结构。

③ 教"最简"——分数、图形、规律一律回到最简形，呼应书中的简单性法则。

④ 练"对手视角"——每走一步自问"对方怎么反制"，培养可逆 / 优超式自检。

⑤ 把数学当游戏——用"必胜策略"点燃兴趣，但始终落到"结构与守恒"的本质。

### 支架三：数轴上的"夹逼数"（理解"{L|R} 记号 / 简单性法则"）

第2章 {a|b} 记号与"简单性法则"——值是最夹在左右最优选择之间、且最简的数。

适合年级：四年级（分数认识、分数大小比较）。

操作步骤：① 在数轴上标 0 和 1；② 说"有一个数，左方只能走到 0，右方只能走到 1，它是谁？"引出 ½={0|1}；③ 再玩"左到 ½、右到 1，它是谁？"引出 ¾={½|1}；④ 让学生用"夹在中间、取最简"判断 3/8 与 5/8 的位置，而非机械通分。

观察点：学生能否用"它夹在 __ 和 __ 之间，而且已经最简"来解释分数大小——能则表明建立了关系性数的观念。

### 支架四：取火柴尼姆（二进制 / 异或启蒙）

第2–3章 拧数 *n、斯普莱格—格隆第理论——无偏博弈等价于尼姆堆，胜负由"配对抵消"决定。

适合年级：五年级（奇偶性、简易二进制）。

操作步骤：① 摆 3 堆火柴（如 3、4、5 根），每次从一堆取任意根，取最后一根者胜；② 先玩"两堆相等"特例，发现"模仿对手让两堆永远相等即赢"；③ 再玩三堆，让学生尝试"先手能否一步造出两堆相等"；④ 揭示规则：能配对抵消（异或为零）则后手赢，否则先手赢；⑤ 用"1 根=1，成对错开"做小学版异或体验（不强行讲二进制）。

观察点：学生能否用"把堆配成相等/相消"判断该不该先手走——能配对思考即触及"不进位加"的雏形。

### 三、后续修正与边界

书中也坦诚自身边界：序言明言"本书并非一本游戏数学的百科全书""仍遗漏许多游戏"；第2章增补指出"两个有限博弈之和可以永远玩下去"（若分支含无限走法序列），说明"相加必终止"需额外条件。对小学教学而言，这意味着：策略数学的思想原型可放心用，但其严格的超限、热博弈部分需择龄、择点，不可照搬进课堂。

说明：三水平对应儿童认知框架的"动作 → 表象 → 符号"三阶，与书中"先尝布丁滋味（动手）→ 找简单性（表象）→ 形式化 {L|R}（符号）"的推进完全一致。

第 七 篇

## 大概念双视角

对应第六层必备：儿童角度 + 教师角度 各提大观念

### 一、站在儿童的角度

◎ 儿童最该建立的学科大观念

"数学是一局可以提前想好的游戏——先拆开看结构、找规律，比急着算更重要；赢了要知道为什么赢。"

对儿童而言，这本书落地为一句话：遇到难题别慌，先想想"它能拆成几块""谁先走谁划算""有没有更简单清楚的画法"。数学不是背答案，而是像下棋一样有策略、有守恒、有最优。

### 二、站在教师的角度

★ 教师最该抓住的学科本质与教学核心

"策略数学的本质是'结构分解 + 不变性守恒 + 化繁为简'；教数学要教'必胜策略思维'，让儿童在游戏中长出有序思考与关系性数的观念，而非只求一个对错。"

对教师的备课启示：把"分类—分解—找规律—有序—优化"这条线，作为策略类、规律类、运算类课的隐性主线；把"数的博弈观"作为分数教学、数轴教学的深层支点；把"可逆/优超"作为解决问题策略单元的方法论。
