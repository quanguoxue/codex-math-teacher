第一篇

## 俯瞰全貌

对应第一层：全书骨架（部分→核心主张→教学价值）

本书的核心主张只有一句话：让"问题"成为儿童学习数学的目标、动力和途径。作者开篇即引用李政道先生的话点题——

"要创新，需学问，只学答，非学问，问愈透，创更新。"（书中序言《用"问题"引领儿童数学学习》）

— 序言，第1页

作者进一步指出，当前数学教学里儿童"发现和提出问题的机会比较少"，即使有问题也"因为没有'外显'机会而失去深入思考的机会"。其立论根基是：儿童天生充满好奇心，学习本就是"不断发现和提出、分析和解决问题的过程"。本报告以小学数学教师备课为视角，把全书三大部分拆解为"如何让儿童敢问→会问→用问题学"三步阶梯。

### 一、全书三大板块与教学价值

|部分|核心主张|对"数与运算"备课的教学价值|
|---|---|---|
|第一部分鼓励儿童产生问题|营造宽松提问环境，用情境图、裸情境、挑战性任务、体验活动、"What if not…"、讲数学故事七种策略，让儿童"敢问、有话问"。|在"倍的认识""乘法意义""除法竖式"等运算课题上，先让儿童自己从情境里长出真问题，避免直接灌输法则。|
|第二部分促使儿童持续思考|用联想、猜想、问题接龙、问题链、提问本/提问角五种机制，让问题"不断延续、深入、被认真对待"。|把运算中的"为什么从高位算起""除法有分配律吗"这类深层疑问，变成可以持续探究的课题。|
|第三部分问题引领儿童学习|以儿童的真问题组织整节课，回应问题、梳理问题、用问题驱动探究（案例含"密铺""莫比乌斯带"）。|把"数与运算"的课堂主线从"讲算法"扭转为"围绕儿童的问题展开运算意义的建构"。|

★ 全貌一句话

这本书不是讲"怎么解题"，而是讲"怎么让儿童自己长出数学问题，并用问题把运算学习往前推"。对"数与运算"教学最大的启示是：运算意义与法则，都要从儿童的问题里长出来，而不是从教师的教案里灌进去。

第二篇

## 解析核心（数与运算）

对应第二层：核心概念深挖（指定领域·跨章成线）

按"数与运算"领域，把散落各章的案例串成一条线：运算意义的原初理解 → 运算概念（倍）的意义建构 → 运算规律的探究 → 计算法则的理解 → 数感与运算中的规律。每一环都用书中原话锚定。

### 一、运算意义的原初理解：从"讲数学故事"开始

二年级"乘法"一课，于老师让儿童给"4×6"编故事。书中实录了7个儿童的不同故事：买气球、插花、五边形聚会、小正方形阵列、买衣服、小袋鼠跳格……作者点明关键——

"'4×6'的算式在有些故事中表示为4个6相加的含义，而在有些故事中又表示6个4相加的含义，不过不论是何种表达方式，都能够看出学生已经进一步理解了乘法运算的含义。""理解数学概念的意义，运用数学的眼光观察世界，无疑是儿童发现和提出问题的基础。"

— 第一部分七·《给算式讲故事吧》，第49—50页

教学启示：运算意义（加、减、乘、除四则）不能靠背定义获得，要靠"符号↔生活"的双向翻译。当儿童能给"4×6"讲出6种故事，他才真正拥有乘法意义——这恰是后续所有运算学习的地基。

### 二、运算概念"倍"的意义建构：在认知冲突中生成

"倍的认识"一课，高老师呈现小鸡一家图后，儿童自发提出"小鸡是母鸡的几倍""母鸡是公鸡的几倍"。但儿童答案出现分歧：

"有的学生高高地举起手：'我认为小鸡是母鸡的1倍，母鸡有4只，小鸡比母鸡多了4只，所以是1倍。'一个小男孩……'我觉得小鸡应该是母鸡的3倍，母鸡有4只，小鸡和母鸡一共有12只，12里面有3个4只，所以是3倍。'有的学生满脸疑惑：'到底是几倍呢？好像都有道理。'"

— 第一部分二·《到底是几倍呢？》，第14—15页

更精彩的是课尾，一个儿童追问"公鸡是小鸡的多少倍"，引发争议。高老师没有否定，而是说"其实从某种程度上看也可以说小数是大数的多少'倍'，但是'倍数'就要用分数来表示了，到了三年级我们会学习分数"——把一个错误疑问变成通往分数的桥梁。

教学启示：倍是"两个量之间的比较关系"，儿童最初的迷思（把"倍"等同于"多出几"）恰是意义建构的入口。保留冲突、不急着给标准答案，才能让"倍"的概念真正建立。

### 三、运算规律的探究：用"What if not…"把法则"问活"

四年级"乘法分配律"探究后，姚老师不急着练，而是抛出"What if not…"（如果不这样，又会是怎样）：

生1：如果不这样，把乘法换成除法，除法有分配律吗？生2：把"×"换成"+"会怎样？生3：换成"−"会怎样？生4：换成""会怎样？

— 第一部分六·《What if not …》，第42页

书中援引布朗和沃尔特的"否定假设法"：先列出问题属性，再改变某些属性提出新问题。这就把"乘法分配律"从一个孤立结论，变成一张可延展的"运算规律关系网"。

### 四、计算法则的理解：把"规定"还原成"可探究的问题"

杨老师的提问角里，儿童问："除法竖式为什么要从高位开始，不从个位开始？"三年级学完两位数除以一位数后，也有儿童追问"为什么这学期的除法竖式要从最高位开始算"。书中说：

"正是在没有束缚的时空中，这个令人好奇的问题才得以产生，它又引领儿童的思维逐步走向深刻……同时也加深了他们对知识的理解。"

— 第二部分五·《设立提问本和提问角》，第86页

教学启示：计算法则（从高位算起、进位、数位对齐）常被当成"规定"死记。而儿童自发的"为什么"提示我们：法则应当被当作可解释、可质疑的对象，而非权威命令。

### 五、数感与运算中的规律：在"加法表"里看见结构

一年级"探索规律（加法表）"中，儿童填涂加法表后发现"出现次数最多的和是10，最少的是2和18"，吴老师随即抛出疑问引发探究，儿童恍然大悟：能组成10的数字组合最多，组成2、18的只有1+1、9+9。

教学启示：运算中的"规律"是数感的土壤。当儿童从一张加法表里"看"到和的分布结构，他获得的不是一道题的答案，而是对"数之间关系"的整体直觉——这正是运算教学的高阶目标。

★ 数与运算四条主线小结

① 意义先行（先懂运算"是什么"，再练"怎么算"）；② 概念在冲突中建构（倍、分数）；③ 规律在"提问"中延展（分配律→其他运算）；④ 法则在"质疑"中理解（为何从高位算起）。四线汇成一句：数与运算的教学，应从"儿童的问题"出发，回到"儿童的理解"。

第三篇

## 共情学情

对应第三层：学情诊断要点（理论→课堂症状对照）

用书中案例反观一线"数与运算"课堂，教师常困惑"明明会做，换个问法就错"。本书揭示：那不是"粗心"，而是儿童从未真正拥有运算的意义与提问的主动权。下面把书中理论对应到可观测的课堂"症状"。

### 一、三类典型"假会"须警惕

列式假会：能写"4×6=24"，却讲不出一个生活故事——运算意义未内化。

术语假会：能说"小鸡是母鸡的2倍"，但换个"公鸡是小鸡的几倍"就错——迷思概念未澄清。

步骤假会：会做除法竖式，但不知"为何从高位算起"——法则沦为机械程序。

### 二、给教师的"读懂儿童"提醒

"学生提不出问题时，教师可……提出自己的真实好奇，引发儿童观察与交流。"（吴老师就加法表提出"为什么10最多、2和18最少"的疑问）

— 第一部分一·《老师有一个疑问》，第7页

书中给出的关键姿态是：当儿童提不出问题，不是儿童"没问题"，而是需要教师示范"如何好奇"。教师要做"提问的示范者"与"问题的倾听者"，而非"答案的供给者"。

◎ 学情诊断一句话

"会做≠理解"。数与运算课堂上，凡儿童说不清"为什么"、讲不出"生活原型"、提不出"还能怎样"的，都可能是假会。先诊断"是真理解还是假会"，再决定教不教、怎么教。

|书中理论/现象|课堂可观测"症状"|根源诊断|
|---|---|---|
|儿童提问机会少、无"外显"渠道（序言）|一让提问就沉默；只等老师给问题；作业全对但说不出"为什么"。|课堂把"解题"当唯一目标，儿童的问题被压抑。|
|"倍"的迷思概念（第14—15页）|说"小鸡是母鸡的1倍"；把"倍"当"多出几"；只会套"大数÷小数"。|未建立"倍是两个量的比较关系"，死记结论。|
|运算意义未真正理解（第49—50页）|会列"4×6=24"却讲不出故事；乘除混淆；只背口诀不解意。|"符号↔生活"翻译缺失，属"假会"。|
|法则被当"规定"接受（第86页）|机械按步骤算，问"为何从高位算起"答"老师说的"；换形式就错。|计算法则未经历"可质疑、可解释"的建构。|
|"课下研究"易遗忘（第87页）|课上提的问题下课就忘；提问热情减退；问题无后续。|问题缺少固定载体与持续回应机制。|

第四篇

## 建构支架

对应第四层：3—5个可落地学习支架（理论/年级/步骤/观察点）

以下五个支架均源自书中理论原型，普通教室无需额外材料即可实施，每项标注：对应理论 / 适合年级 / 操作步骤 / 观察点。

### 支架一：算式故事卡（对应"讲数学故事"理论）

对应理论：第一部分七"给算式讲故事吧"——用生活故事理解四则运算意义（第49—50页）。

适合年级：二年级（乘除法入门）及三年级（复习四则意义）。

操作步骤：①教师给出算式如"4×6"；②学生写/画一个生活故事并列出算式；③同桌互讲，全班分享不同故事；④追问："这个故事里4和6分别指什么？"⑤引导发现同一算式可有"4个6"或"6个4"两种含义。

观察点：儿童能否脱离算式讲出完整情境；是否混淆"几个几"；能否指出算式中每个数的实际意义——能讲清即"意义真理解"。

### 支架二："倍"的意义冲突单（对应"倍的认识"理论）

对应理论：第一部分二"到底是几倍呢？"——在认知冲突中建构"倍"的比较关系（第14—15页）。

适合年级：二年级下册"倍的认识"。

操作步骤：①呈现"母鸡4只、小鸡12只、公鸡3只"图；②让学生独立写"谁是谁的几倍"并写理由；③收集分歧答案（1倍/2倍/3倍）板书；④小组辩论"到底几倍"；⑤教师引出"倍=一个数里有几个另一个数"；⑥保留"小数能是 large 数的倍吗"作延伸。

观察点：儿童能否用"12里有几个4"来解释"3倍"；是否仍把"倍"等同于"多几"——能正确用"包含除"解释即过关。

### 支架三："What if not…"运算探问表（对应否定假设法）

对应理论：第一部分六"布朗和沃尔特否定假设法"——列出属性再改变以生新问题（第42—44页）。

适合年级：四年级（运算定律）、五年级（运算推广）。

操作步骤：①学完一个规律（如乘法分配律）；②全班列出它的"属性"：运算符号×、结构(a+b)×c、加数个数2；③逐项问"What if not"：换成÷？换成+？换成三个数？④学生每人提1个新问题并尝试举例；⑤课尾分享"最有价值的问题"。

观察点：儿童能否提出"可检验"的真问题（而非胡问）；能否举反例或特例——能主动质疑规律边界即达高阶。

### 支架四："已知—未知"提问梳理表（对应挑战性任务理论）

对应理论：第一部分四"运用已知和未知梳理表为儿童提问提供支架"（第63—64页附近）。

适合年级：三—五年级"数与运算"综合课、复习课。

操作步骤：①给一个运算情境（如"节水宣传手册"中的统计与计算）；②两栏填写：已知（已给数据/已学算法）、未知（想知道什么/还不会算的）；③学生从"未知"栏提炼可探究的数学问题；④选出核心问题全班研究。

观察点：儿童能否从"未知"中生出具体、可算的问题；问题是否与核心内容相关——能区分"核心问题"与"边缘问题"即见思维条理。

### 支架五：提问本 + 提问角（对应"提问本提问角"理论）

对应理论：第二部分五"人手一个提问本，及时记录真问题；让问题'搬家'放入提问角"（第86—87页）。

适合年级：全年级通用，数与运算课尤佳。

操作步骤：①每人发"提问本"，约定随时记录运算中的真疑问（如"为何从高位算起"）；②每周设"提问角"，把暂时解不开的问题贴出；③感兴趣的同学课下探究，把思考过程贴回角里共享；④定期评选"最有价值问题"。

观察点：提问本中是否出现"为什么类"深层疑问（而非只记答案）；提问角是否形成"提问—探究—分享"闭环——有持续追问即说明问题意识已生根。

★ 支架设计原则

五个支架共同遵循书中"原汁原味"要求：每个都对应一个可查的理论原型，且都不依赖精美教具——一支笔、一张表、一本子，普通教室明天就能用。

第五篇

## 理论溯源

对应第五层：学术史定位（继承/推动/被发展 + 3句话贡献 + 修正）

### 一、核心理论在学术史上的位置

继承：本书"问题引领学习"直接承接波利亚（G. Polya）《怎样解题》中"解题即发现"的思想，以及建构主义"知识在主体与客体互动中建构"的立场；并呼应《义务教育数学课程标准》将"发现和提出问题的能力"列为总目标。

推动：把"提出问题"从解题的附属环节，提升为贯穿课前—课中—课后的独立学习主线，并用大量一线案例把"提问教学"操作化、可复制。

被发展：书中"What if not…"方法明确援引布朗和沃尔特（S. Brown & M. Walter）的"否定假设法"（"先列属性，再改变属性生新问题"），这是国际数学教育界"问题解决与问题提出"研究的经典成果；后续"创客教育""项目式学习(PBL)"进一步把"儿童真问题"推向课程设计中心。

◎ 量规使用提示

观察重点不是"会不会算"，而是"会不会问、懂不懂意、敢不敢疑"。L1→L2 看意义是否建立，L2→L3 看能否质疑与迁移，L3→L4 看能否自主用问题驱动学习。此量规与第四篇五个支架联动：支架是"教—学"活动，量规是"评"的标尺，构成教—学—评闭环。

### 二、三句话讲清本书学术贡献

① 它把"让儿童提出问题"从一句口号，变成有环境、有方法、有载体的系统教学策略（七问法与五持续机制）。

② 它用"问题"打通了"学与教"——儿童的问题既是学习目标，也是学习动力，还是组织课堂的路径。

③ 它在"数与运算"等具体领域证明：运算意义与法则，完全可以从儿童自己的问题里长出来，而非靠教师灌输。

### 三、后续研究的可能修正与边界

时间成本：鼓励自由提问会压缩"刷题"时间，需在"提问空间"与"教学进度"间取舍（书中也承认"课堂教学时间有限，要有所取舍"）。

问题质量：并非所有儿童问题都有教学价值，本书用"问题分类处理表"（核心相关/不直接相关）应对，但一线仍可能被低效问题拖慢。

评价缺位：原书重"如何问"，对"提问能力如何评价"着墨较少——这正是本报告第六篇"学习水平量规"要补的短板。

第六篇

## 萃取要径

对应第六层：教师行动纲领(≤5条) + 学习水平量规(≥3级)

### 一、教师行动纲领（可贴桌）

① 先护问，再教书——每节课留出口子，让儿童敢把"为什么"说出来。

② 意义先于算法——讲运算先讲"是什么、为什么"，不急着练"怎么算"。

③ 把冲突当资源——儿童的"错答案"（如倍=多几）是概念建构的入口，别急着纠正。

④ 教给提问方法——用"What if not…""已知未知表""讲数学故事"给儿童可攀爬的支架。

⑤ 让问题有去向——用提问本、提问角把真问题接住、延续、共享，不让它下课即忘。

### 二、学生学习水平量规（评有维度·数与运算提问与理解）

|水平|名称|学生典型表现（课堂可观测）|教师下一步|
|---|---|---|---|
|L1|敢问·依样|能在教师示范后照着提问题；能复述运算步骤但讲不出意义；提问多为"这道题怎么做"。|多示范"如何好奇"，用情境图/故事降低提问门槛，不批评"笨问题"。|
|L2|会问·明意|能从情境自发提出问题；能给算式讲出生活故事，说清运算意义；对"倍"等概念有基本正确理解。|引入"What if not…""已知未知表"，推动从"提一个问题"到"提一类问题"。|
|L3|深问·质疑|能质疑法则（如"为何从高位算起"）；能改变条件生成新问题；能区分核心问题与边缘问题并持续探究。|用提问角承接深层疑问，组织"问题接龙/问题链"，把个别问题变成全班课题。|
|L4|善用·创生|主动用问题组织自己的学习；能把运算规律迁移到新情境；能创作数学故事/绘本并提出延伸问题。|提供挑战性任务与高峰体验，鼓励把探究过程写成"可爱作业"分享全班。|

第七篇

## 大概念双视角

大概念提取：儿童角度 + 教师角度

### 一、站在儿童的角度

◎ 儿童最该建立的大观念

"运算不是一堆要背的口诀和步骤，而是我用来描述和解决生活里'有多少、差多少、几倍、怎么分'等真实问题的工具；而提出好问题，是学会运算的第一步。"

对儿童而言，数与运算的终极大观念应是：我会算，是因为我先想知道"到底怎样"；当我能给自己出的算式讲出故事、能问出"如果不这样会怎样"，我就真正拥有了数学。

### 二、站在教师的角度

★ 教师最该抓住的学科本质与教学核心

"数与运算教学的主线，是'运算意义的理解'与'运算规律的探究'，而非'算法的熟练'；而这条主线必须由儿童自己的问题来牵引。"

教师的核心任务有三：一是营造敢问的环境（约定、倾听、示范好奇）；二是提供会问的支架（故事、否定假设、已知未知表）；三是接住并延续真问题（提问本、提问角、问题链）。把"教算法"还原为"用儿童的问题建构运算意义"。

第八篇

## 实践转化

核心收获 + 下一步行动

### 一、本次研读的核心收获

观念转变：数与运算课的真实起点不是"例题"，而是"儿童的问题"。

方法清单：七条催生问题策略 + 五条持续思考机制，均已对应到具体年级与操作步骤。

诊断工具：用"三类假会"（列式/术语/步骤）识别运算学习中的表面掌握。

评价标尺：四 level 学习水平量规，把"会不会问、懂不懂意、敢不敢疑"变成可观测指标。

### 二、下一步行动（本人/校本教研可落地）

下周即试：在二年级"乘法"或"倍的认识"课上，用"支架一算式故事卡 / 支架二冲突单"替代直接讲授，记录儿童提问质量。

建立提问本：所教班级全面启用"提问本+提问角"（支架五），每月评选"最有价值问题"并公示探究过程。

运算定律课改造：四年级"运算定律"单元，每节课尾加 5 分钟"What if not…"探问（支架三），收集儿童生成的"规律关系网"。

校本教研主题：以"数与运算：从儿童的问题出发"为月度教研主题，用本报告第四篇支架与第六篇量规做课例研讨。

补研究短板：结合本报告量规，设计"儿童提问能力"校本评价量表，弥补原书评价维度不足。
